# Mapas do Eu Kasconta

Arquivos de mapa (PMTiles) que o app baixa para usar sem internet. Gerados pelo workflow "Mapas".

Dados © colaboradores do OpenStreetMap, disponíveis sob a licença ODbL (https://www.openstreetmap.org/copyright).
Mapa-base vetorial: Protomaps (https://protomaps.com), obra produzida a partir desses dados.
